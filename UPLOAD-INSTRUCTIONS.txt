RESTORE THE WEBSITE

1. Extract this ZIP.
2. Open the extracted folder.
3. In the GitHub repository mabiordeng/mabiordeng.github.io, replace the existing site files with ALL files from this folder.
4. Keep the files at repository root.
5. Commit the upload.
6. In Settings > Pages, publish from main / (root).
7. After deployment, open https://mabiordeng.github.io/ and hard-refresh with Ctrl+F5.

Do not upload the ZIP itself.
